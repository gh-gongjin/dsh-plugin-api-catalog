# dsh-plugin-api-catalog

dsh（DeepSeek Harness）插件：把社区维护的公开 API 目录表装成本地可读、可搜、可批注的一页。

- **目录源**：`public-apis-cn`（中文）为唯一真源，取不到时按登记顺序降级到 `public-apis`（英文）——共五档来源（两真 + 三降级），每档的失败原因单独落台账。
- **界面**：五个页签 —— 目录 / 常用API / 变更 / 我的笔记 / 设置。首屏数据由宿主端口下的插件路由提供，SSE 持续推增量。
- **运行时零抓取**：只有定时检查那一轮会发 GET；用法层与内置预译表都是构建期产物，随发版走。

## 数据口径（读代码前先看这几条）

| 口径 | 落地 |
| --- | --- |
| 抓取全程只读 GET、不带凭证、不写上游 | `lib/fetch.js`，五档来源逐档登记结果与原因 |
| 现译出网只走**登记的渠道域名** | 白名单从 `TRANS_ENDPOINTS` 派生，判据不手抄第二份 |
| 密钥/凭据永不回显、不进 prefs、不进快照 | 只进宿主 `secrets` 表；带 `user:pass@` 的代理地址也不落 prefs |
| 界面上的每个时刻都点名来源字段 | `meta.fetchedAt` = 条目是哪一版（只在上游 sha 变化时前进）；`meta.lastCheckedAt` = 什么时候查过（每轮都前进，含「没变化」那一轮）。页头那枚状态 pill 念后者，副标题「快照」念前者 |
| 上游写了「未知」就照实念 | 不替上游把 `Unknown` 圆成结论（`CORS` 那一列的悬停措辞为此改过一版） |

## 检查节拍

- 间隔四档：1 / 6 / 12 / 24 小时，出厂默认 12 小时（`DEFAULT_PREFS.intervalMin = 720`）。
- 启动后隔 `firstSyncDelayMs`（5 s，给宿主 `storageDomain` 的注入回调留落地窗口）跑第一轮，之后由宿主 timer 驱动；失败按 `BACKOFF_STEPS = [1,2,4,8]` 抬档，成功或「源内容没变」把档位写回 0（退避不会自己越拖越长）。
- 单飞锁：上一轮没结束时再触发返回 rejected promise，不从定时器回调里同步 throw。

## 中文说明

1. **内置离线预译**：1965 种唯一原文全在表里（`lib/desc-zh.js`，`DESC_ZH_AT = 2026-10-06`），运行期零模型调用、零额外出网。原文变了就退回原文，不指鹿为马。
2. **现译（可选，默认关闭）**：渠道六档 —— 免密钥的「免费接口」（Google 网页版翻译，**不是官方授权接口**）、出厂默认「宿主模型」、百度 / 腾讯 / 阿里 / 讯飞四家官方接口。厂商签名逐家用官方算例钉死。
3. **出网代理**：三档（跟随系统 → 自定义地址 → 直连）。「跟随系统」先读环境变量、再读 Windows 注册表（**只 `reg query`**，不改系统）。CONNECT 隧道只用 Node 内建（`node:net` / `node:tls` / `node:https`），零第三方依赖；隧道超时 8 s，故意小于现译总闸 12 s。

## 装与跑

```bash
# 挂载（link: 方式，指向本目录）—— 改动与撤销 link 后需要完全退出宿主再启动
# 依赖：Node 内建模块，无第三方运行时依赖
for f in test/*.test.mjs; do node "$f"; done   # 14 套件 / 439 项 / 0 失败
```

测试默认不外发真请求：夹具是两份上游 README 的**真片段**（`test/fixtures/`），形状照着真宿主复刻（含宿主 `open()` 的校验与重域名口径）。依赖时刻、序号、先后的判据**故意跑在真时钟上** —— 假时钟会让这类前提天然成立，判据就变成空枪（这一点在 S18、S19 各翻过一次车，都有记录）。

判据之外还有**变异电池**（`test/_battery-s1x.mjs`）：逐发改坏控制流，确认对应判据真的会红、且改动能字节级还原。绿不等于有效。

## 已知边界

- **「常用API」页目前只有壳**：上游表里没有调用量、运行时零抓取 ⇒ 拿不出「谁用得多」，那一页只摆数得出的读数，不排名次。频率来源待裁定（U-14）。
- 换源那天起，内置预译表对中文源的命中大幅下降（表是按英文原文整理的），那部分走现译或照显原文。
- YAML 规范这一版没解（零第三方依赖 ⇒ 没有可靠的 YAML 解析），用法层只收 JSON 规范；对不上的条目界面不显用法层。

## 目录

```

lib/                     域定义、来源登记、抓取、解析、存储、查询、同步、翻译、渠道、网络、能力位、内置表
test/                    14 套件 + 夹具 + 变异电池
docs/design-spec.md      设计与裁定的全程记录（含被推翻的旧口径，原样留着）
prototype/               原型对照页
tmp/                     本机走查产物（截图、读数字、浏览器 profile）—— 不进仓库；
                         例外只有 .mjs 脚本：生成器与几何走查脚本被文档逐条指向
```
